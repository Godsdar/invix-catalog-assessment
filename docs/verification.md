# Проверка реализации

Дата: 20 октября 2026. Локальный запуск: Docker, Linux arm64 containers.

- `npm run build` и `npm run typecheck`: успешно, Next.js 16.4.2.
- `docker compose --profile test run --rm tests`: **15 passed**. PostgreSQL 17 и MinIO настоящие, Telegram gateway подставной. Тестовая БД и bucket отделены от приложения.
- MinIO успешно собран из закреплённого официального upstream commit; init создаёт bucket и схему, API readiness возвращает 200.
- Запущены по две реплики API, Next.js, webhook и worker. API/webhook healthy, оба воркера running. Для проверки запуска ролей использован явно фиктивный токен; реальный Telegram не вызывался.
- После остановки одной реплики каждой роли выполнено 10 последовательных проверок: страница каталога 200, API readiness 200, webhook без секрета 403. Все прошли.
- В браузере проверено пустое состояние каталога.

Интеграционные тесты охватывают создание товара, API-выдачу фотографии, разграничение прав, повторные updates, восемь конкурирующих обработчиков, сохранение диалога, пагинацию и повтор обработки после сбоя между S3 и PostgreSQL.

Ограничения: реальная доставка Telegram, HTTPS и открытие страницы внутри установленного клиента Telegram не проверялись, поскольку для них нужны действующий токен бота и публичный адрес. Инструкция подключения находится в README. CI настроен в GitHub Actions; состояние его запуска проверяется отдельно по GitHub.
